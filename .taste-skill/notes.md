# 디자인 노트 — SnapHost (achromatic-ledger, devtools workspace)

## 1. 데이터와 일 (Inventory)
- **핵심 객체**:
  - **프로필(Profile)**: 이름, 활성화 여부(`enabled`), 시스템 기본 여부(`is_system_base`), 호스트 매핑 본문(`content`), 수정 시각
  - **호스트 엔트리(HostEntry)**: 대상 IP(`127.0.0.1`, `::1` 등), 선택적 로컬 프록시 포트(`:3000`, `:8080`), 도메인 목록(`web.myapp.dev`), 인라인 주석
  - **포트 매핑 상태(PortMappingStatus)**: 도메인 → `IP:PORT` 라우팅 규칙 및 로컬 TCP 포트 응답 여부(`alive`)
  - **시스템 상태(SystemStatus)**: `/private/etc/hosts` 즉시 쓰기 권한 여부(`hosts_writable`), 원본 백업 존재 여부, GitHub 최신 릴리즈 상태
- **규모**: 프로필 3~15개, 프로필당 도메인 규칙 5~200줄 (원격/광고차단 병합 시 수천 줄)
- **사람**: macOS(Apple Silicon) 환경의 웹/앱/백엔드 개발자
- **가장 잦은 일**:
  1. 좌측 목록(또는 메뉴바)에서 프로필 스위치를 한 번 눌러 개발 환경 즉시 전환 (0ms)
  2. 현재 프로필에 새 로컬 도메인(`127.0.0.1:3000 app.local`) 추가 또는 `Cmd + /`로 특정 줄 주석 토글 후 `Cmd + S` 저장
  3. 로컬 포트 프록시 연결 상태 및 도메인 중복 충돌 확인

## 2. 화면별 한 가지 질문 (One Question per Zone)
- **좌측 사이드바 (프로필 원장)**: *"지금 어떤 환경이 켜져 있고, 전체 몇 건의 도메인·포트가 매핑되어 있나?"*
  - 제목 아래 한 줄 요약(`tabular-nums`): `활성 n개 · 도메인 n건 · 프록시 n건`
  - 각 프로필 행(40px): 프로필 이름, 활성 여부 스위치(28×16px), 기본(BASE) 배지
- **우측 메인 캔버스 (프로필 편집기 & 라우팅 상태)**: *"이 프로필이 어떤 도메인을 어디로 연결하며, 문법 오류나 충돌이 없나?"*
  - 상단 헤더: 프로필 이름 인라인 수정, 활성 상태 칩, 빠른 규칙 추가(`+ 규칙 추가`), 저장(`⌘S`)
  - 본문: 줄 번호가 정렬된 고정폭 호스트 코드 편집기 + 하단 실시간 라우팅/문법 원장 바
- **대화상자 (`<dialog>`)**:
  - 내장 WebView에서 동작이 불안정하고 맥락을 끊는 `window.prompt`, `window.confirm`, `window.alert`를 전면 제거하고 네이티브 `<dialog>` 모달과 하단 토스트(Toast) 알림으로 일원화.

## 3. 얼굴 (Face & Colour Budget — `achromatic-ledger`)
- **바탕(Ground)**: 원장/계측 도구 톤의 저채도 블루그레이 `#f2f4f7` (다크 모드 `#0a0a0a`). 패널과 카드는 순백색 `#ffffff` (다크 모드 `#121212`).
- **무채색 크롬(Ink Chrome)**: 주요 실행 버튼(저장, 추가)은 브랜드 컬러 대신 **잉크 블랙(`#141414` / 다크 `#ffffff`)**을 사용. 정적 그림자(`box-shadow`)와 그라데이션(`linear-gradient`)은 `0`으로 유지하고 `1px` 헤어라인(`#e6e6e6` / `#262626`)으로만 구획.
- **유일한 색 (`--hue: #1d5fbf` / 다크 `#6f9cf0`)**: 화면 전체 픽셀의 1% 미만으로 제한하며, 오직 **"지금 활성화된 상태"**(켜진 프로필 스위치, 현재 선택된 행의 좌측 인디케이터, 활성 프록시 포트 신호)에만 부여.

## 4. 이 제품만의 요소 (Signature)
- **"라이브 라우팅 바 (Live Route Strip)"**: 편집기 하단에 현재 활성화된 `도메인 → :포트` 매핑과 로컬 서버 응답 상태를 한 줄의 원장 칩으로 표시하고, 편집기 상단에서 IP/포트와 도메인을 입력해 즉시 정형화된 포맷으로 줄을 삽입하는 빠른 입력기 제공.

## 5. 서체 및 기계적 기호/이모지 제거 (Typography & Anti-Slop)
- **서체**: UI 전반은 `Pretendard Variable, Pretendard, -apple-system, sans-serif`를 사용하고, IP 주소·포트 번호·줄 번호·집계 숫자에만 고정폭 `Geist Mono, SF Mono, Menlo, monospace`와 `tabular-nums`를 적용.
- **5단계 타이포 스케일 준수**: `24px`(제목), `16px`(섹션/모달 제목), `14px`(본문/리스트/입력창), `13px`(코드), `12px`(보조 라벨/단축키). `10px~11px` 미세 텍스트(micro-label) 전면 제거.
- **이모지 및 em-dash(`—`) 제거**: 기존 화면에 있던 `⚡`, `🔍`, `🔄`, `🛡️`, `🎉`, `🟢`, `⚪` 이모지와 제목의 `—` 기호를 모두 제거하고, `16px` 1.5px 스트로크의 정교한 단색 외곽선 SVG 아이콘 세트로 교체.
